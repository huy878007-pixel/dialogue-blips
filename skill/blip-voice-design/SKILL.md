# Blip voice design

给对话密集的游戏设计**逐字合成音**（每显示一个字符响一次）。

**核心原则：区分度优先于好听。** 玩家的第一需求是"一听就知道是谁在说话"，第二需求才是"好听"。18 个角色里有一个听不出来的，整个系统就失败了。

**第二条：先量后调。** 任何参数决定都应该能说出"为什么是这个数"。说不出来就是在瞎调。

---

## 四步强制流程

这四步是**必须问自己的问题**。跳过任何一步，产出的音色大概率要返工。

### 第 1 步：从台词提取可量化证据

**立绘要真的打开看，不要只读文字描述。** 图上有很多文字没写的东西：
尾音该扬还是该落、眼睛是睁是闭、手在身前交叠还是在指东西。
实例：文字写"闭眼微笑、背后有刀"，看图才发现是**笑着把刀藏在身后**——
这种角色尾音必须上扬（像笑着说完），落下去就变成叹气，整个角色就歪了。

**前置硬性要求：必须有真实台词原文。**

没有原文就**停下来要**，不要用角色描述去"反推台词特征"。实测后果：
一个 agent 拿不到台词，自己编了"我不着急，你有的是时间想"，
据此设计了 95 ms 长尾 + 慢起音；而真实台词是**"快给钱，否则我就让你身败名裂"** —— 
气质完全相反，整套参数作废。

角色描述（"低声、笃定"）只能用来**约束搜索范围**，不能当证据。证据必须是引号里的原句。

**自检**：如果表格里"台词特征"那一列是你写的而不是抄的，这一步没做。

不要从"他是好人/坏人"出发。从**台词的结构特征**出发，问：这句话的方式是什么，不是内容是什么？

| 台词特征 | 读出 | 落到参数 |
|---|---|---|
| 反复使用"所有 / 每种 / 够多"这类集合词 | 他在清点，不在品味 | tick 必须等长等强、音高不游走 |
| 唯一的祈使句却包着礼貌（"我给你两天时间"） | 礼貌的支配欲 | 短起音 + 硬辅音 + 零沙砾 |
| 回复只有两三字（"不错。""成交。"） | 交易型，不闲聊 | 时长必须短（≤65 ms） |
| 自报籍贯而没人问 | 爱表演身份 | 吐字干净，加轻微爆破层 |
| 全大写喊叫（"我只是想买点吃的！"） | 委屈不是威胁 | 推高音量时**变亮变响**，不要变厚变凶 |

**要求**：每个参数决定都要能指认到一句具体台词。指认不出来 = 那个参数是装饰。

### 第 2 步：选音区——用对数中点，不用感觉

**可执行流程**（不要凭感觉"挑个空的地方"）：

1. 把所有已有基频排序
2. 逐个算相邻间隔的**半音数**：`12 × log2(f_high / f_low)`
3. 只保留**两侧都 ≥1.5 半音**的间隔——这些才是真正塞得进新角色的位置
4. 每个候选里取**几何中点** `sqrt(f_low × f_high)`
5. 在候选里选：既要够宽，也要符合角色的语义档位（高位给"不正常/上层"，中位给普通人）

**判断标准：相邻角色至少差 1.5 半音，最好差 2.5 半音以上。**

> 实测：一个 22 角色的库，21 个相邻间隔里**只有 3 个**真的塞得进新角色。
> 低音区（100–220）是最先满的——想做"低沉"的新角色时，数学上大概率已经没有位置了。

> 低音区（100–220 Hz）很快就会饱和。超过 6 个角色后，新增角色优先考虑中高区。

### 第 3 步：查冲突——列出最近的 3 个，逐项对比

**这一步最容易跳过，也是返工的最大来源。**

不只比音高，要比**结构**。两个角色可能音高差很远，但"都很高、都多层、都带金属层"——那就会混。

对每个最近的邻居，回答：**"如果他俩先后说话，我靠什么区分？"** 答案必须是**三个以上**的具体参数差异。

同时检查**隐性冲突**：你的某一层会不会和另一个角色的主层同频？
（例：在 247 Hz 加一层胸腔共鸣，而另一个角色的主层就是 248 Hz → 单独听那层会被认成他。）

### 第 4 步：定验收——可测阈值 + 反向验证

**趣味只能听，疲劳和撞车可以量。**

必须给出可测的阈值：

| 检验 | 方法 | 阈值 |
|---|---|---|
| 确定性 | 同一参数渲 100 次，逐字节比对 | 100% 一致 |
| 最短样本 | 只播最短的一句话，盲听报名字 | 60 ms 内认得出 |
| 区分度 | ABX 5 选 1（自己 + 最近 4 个），20 轮 | ≥90% 正确 |
| f0 轨迹 | 前 60 ms 中位斜率 | 按设计意图（正/零/负） |
| 亮度 | 3 kHz 相对 500 Hz | ≤ −12 dB（除非故意毛躁） |
| 刺耳度 | >6 kHz 能量占比 | < 0.2%（故意毛躁 < 1%） |
| **响度** | 整段 A 计权 RMS | 与相邻角色差 ≤1.5 LU |

**反向验证（最有用的一步）**：造三到四个**故意做错的版本**，要求指标能把它们排除。

```
错版 (a) 把设计的滑音归零       → 区分度指标应该掉分
错版 (b) 加一个高频闪光层        → 与"精致型"邻居的混淆率应该上升
错版 (c) BitCrush 拉到 0.3      → 与"毛躁型"邻居的混淆率应该上升
错版 (d) 时长拉到 100 ms        → 应该被听成"沉吟型"角色
```

**指标排除不了错版，指标就是摆设。**

### ⚠️ 做 A/B 听测前必须匹配响度

实测一个 44 音色的库，**不同音色的 RMS 相差约 6.9 dB**。

响度大的那个天然显得"更有存在感"，人耳会把"更响"误判成"更好"或"更刺耳"。
所以：

- 设计时听到"这个更对" → 先确认是不是因为它更响
- 听到"这个刺耳" → 先确认不是响度造成的错觉，再动滤波器
- 层数多的音色（3–4 层）通常比 2 层的响，比较时要压平

**没有响度匹配的 A/B 结论，有一半是响度在投票，不是音色。**

## 硬公式（不许猜）

AI 在这几个数字上**一定会猜错**。直接用。

### 音高 ↔ 参数

bfxr 的 `StartFrequency` 与赫兹的对应关系：

```
f_Hz = 3528 × (s² + 0.001)          s ∈ [0, 1]
s    = sqrt(max(f_Hz / 3528 − 0.001, 0))
```

**范围 3.5 – 3528 Hz。** 不要把 `s` 当成归一化的 0–1 音高。

### 包络 → 毫秒（**最容易错的一个**）

```
时长(采样) = (attack² + sustain² + decay²) × 100000
时长(ms)   = 时长(采样) / 44100 × 1000
```

**注意**：`1.0` 约等于 **2.27 秒**，不是 1 秒。用线性直觉会算出小 16 倍的结果。

校验（真实项目实测）：

```
A 0.05 / S 0.08 / D 0.22  →  129.9 ms   （实测 130 ms）
A 0.05 / S 0.09 / D 0.24  →  154.6 ms   （实测 155 ms）
A 0.007/ S 0.019/ D 0.036 →  3.9 ms     ← 这是"咔哒"，不是"音"！
```

反解：要得到目标 ms，`a² + s² + d² = ms/1000 × 44100 / 100000`。

### 半音距离（用来看"够不够分开"）

```
半音 = 12 × log2(f_high / f_low)
```

**别用 Hz 差百分比代替。** 100 Hz 差 20 Hz = 3.5 半音（远），600 Hz 差 20 Hz = 0.57 半音（近）。

### 对数中点（用来选空档）

```
中点 = sqrt(f_low × f_high)
```

例：420 与 576 之间 → `sqrt(420×576) = 491.9 Hz`（≈ B4 的 493.88）。

### 刺耳度

```
>6 kHz 的能量 / 总能量
```

正常应 < 0.2%。超过 0.5% 要确认是不是故意的（"毛躁"型角色可以，但要有理由）。

**刺耳的真正原因是谐波，不是音高。** 两个具体的坑：

- 锯齿的谐波按 1/n 衰减但**永不终止**，能量一路铺到 20 kHz。压 `LpFilterCutoff` 只是让它变闷，齿感的刮耳感还在。
- 哨音（7 号）是「正弦 + 20 倍泛音」。378 Hz 时那层泛音落在 **7.5 kHz**——人耳最敏感的频段；849 Hz 时落在 17 kHz，会激起耳机高频共振。**这层泛音和主体音量是 1:0.25，躲不开。**

结论：**要保证不刺耳，主体用正弦**；要"有质感但不刺"，用破碎波（8）或三角（4）。锯齿只留给"粗粝就是性格"的角色。

还有一条听感上限：**女声不要超过 ~950 Hz**。超过之后连三角和正弦都会开始刺。这条优先于"分离度"——宁可音区挤一点，也不要尖。

## 参数语义表

| 参数 | 感知效果 | 常见用法 |
|---|---|---|
| `WaveType` | 材质 | **只有 0/1/2/4/8 能当主体**；3/5 做辅音与气声；6/7/9/10/11 会刺耳或听不出音高。详见下面「波形真身」 |
| `AttackTime` | 起音快慢 | 小=利落（贵族、办事员）；大=沉稳（长者、威胁） |
| `SustainTime` | 保持 | 一般很小，短音不需要长保持 |
| `DecayTime` | 尾长 | **这是"气质"的最大杠杆**：短=不耐烦/傲慢；长=从容/威胁/年老 |
| `LpFilterCutoff` | 亮暗 | 0.45 闷（官僚、阴沉）；0.65 中性；0.80 亮（技术、年轻） |
| `Slide` | 音高滑移 | **负=油滑/疲惫/不屑**；≈0=坦率；**正=雀跃/上扬（很少人用，是个空档）** |
| `VibratoDepth` / `Speed` | 情绪外露 / 稳定度 | 0=不动摇（冷面）；0.03 浅=活人；0.10+ 慢速=**老年感**；0.12 快=神经质 |
| `Overtones` / `Falloff` | 音色厚薄 | 高=暖/实；低=薄/冷/中性 |
| `BitCrush` | 毛刺 | 0=干净；0.05–0.15=一点不体面；0.3+=毛躁（会明显刺耳） |
| `MasterVolume` | 合成器音量 | 留 2–3 dB 余量给"喊叫"变体 |

### 波形真身（**编号必须查，不许猜**）

这套合成器的 12 个编号里，一半不是你以为的东西。名字猜错会直接毁掉整个音色，
而且**在频谱图上不一定看得出来，只有耳朵能发现**。

| 编号 | 真身 | 听感 | 能否当主体 |
|---|---|---|---|
| 0 | 方波 | 空心、硬、电子 | ✅ |
| 1 | 锯齿 | 粗粝、有齿感 | ✅ 但谐波无限延伸，压低通也留着刮耳 |
| 2 | 正弦 | 纯净、无泛音、没有温度 | ✅ **唯一不可能刺耳的载体** |
| 3 | 白噪 | 噪声 | ❌ 只做辅音/爆破 |
| 4 | 三角 | 圆润、温 | ✅ |
| 5 | 粉噪 | 柔和噪声 | ❌ 只做气声 |
| 6 | **tan 正切** | 极刺、会削波 | ❌ 完全别用 |
| 7 | **哨音**（正弦 + 20 倍泛音） | 玻璃感，但那个泛音很毒 | ❌ 见下面「刺耳的真正原因」 |
| 8 | 破碎波（Breaker，抛物线） | 硬朗有棱，谐波自然衰减 | ✅ 常被误当"金属音"，其实是好用的中档材质 |
| 9 | 1-bit 周期噪声 | 噪声 | ❌ |
| 10 | **组合波**（每 4 个相位换一种波形） | 混沌、没有稳定音高 | ❌ 完全别用 |
| 11 | **蜂鸣**（LFSR 周期噪声） | 满增益就是纯噪声 | ❌ 只能 0.05 左右做"杂音"点缀 |

**两个最容易犯的错**：

- 把 **11 号**当主体（看名字以为是"蜂鸣=金属味"）→ 角色一开口就是噪声
- 把 **7 号**当主体（看名字以为是"哨音=清亮"）→ 中音区刺耳，高音区激起耳机共振

**气声层**用 `WaveType 5`（粉噪）+ 小 gain（0.08–0.20）。**气声=亲近感**：气声多显得可亲/虚弱，气声少显得高冷。用反了角色就歪了。

**失谐层**：同一个 hz 加 3–8 Hz 再做一层 → "两个几乎同频的声音"，产生说不出哪里怪的不安感。**比金属噪声高级得多**，但只适合"不正常的角色"。

## 层数与职责

上限 4 层，**每层必须有明确职责**。没有职责的层就是噪音。

| 层 | 典型 gain | 职责 |
|---|---|---|
| 主体 | 1.00 | 承载音高与包络 |
| 辅音 | 0.22–0.30 | 硬起音的噪声，让字头清楚 |
| 气声 | 0.08–0.20 | 气息、年龄、教养 |
| 失谐 / 体量 | 0.20–0.35 | 厚度、双声感、震慑力 |

**材质是第二区分器，音高是第一。** 音区被挤窄时，材质要承担大部分区分工作。

做法是**分族**，不是"全阵容共享一个家族"：

- 每个族 2–3 人，族内靠低通、占空比、时长、气声再分
- **三角不许占多数**。17 个角色 17 个三角 = 只有一个材质，等于只靠音高区分
- 一个族里放谁要看性格：需要"人味"的给三角/正弦；要棱角的给破碎波；要粗粝的才给锯齿

实测有效的一版分配（16 个角色）：破碎波 5、锯齿 2、方波 3、三角 3、正弦 2。

## 已存在的音色是硬约束

给一个已有阵容做新包时，先数清楚**哪些音位是锁死的**：

- **通用音色**（如"男年轻/女年轻/老"）通常不许动——它们对应没有专属立绘的路人
- **不参与本次改动的具名角色**也占着音位

把这些频率先标出来，每个新角色离它们各留 ≥1.2 半音。**这些空档会决定你只能用哪几段音区**，
而不是先想好音高再发现撞车。

如果算下来可用音位不够：**宁可加密间距（1.0 半音）靠材质区分，也不要抬上限**——
抬上限换来的分离度是用"刺耳"买的。

## 完整示例：觅食游客

**第 1 步 · 证据**：三句都在量化集合（"所有美食"/"每种食物"/"种类够多"），从不用味道词 → 他脑子里是清单，不是滋味。回复只有"不错/成交/回头见" → 交易型，不闲聊。

**第 2 步 · 空档**：现有最大空档是 420–576。对数中点 `sqrt(420×576) = 491.9`，取 **494 Hz**（B4 493.88）。离 420 是 **2.81 半音**，离 576 是 **2.66 半音**——两边都够。

> ⚠️ **这个 494 是示例占位，不是"空闲保留位"。** 如果 觅食游客 真的被实现了，
> 494 就被占了；下一个角色要另找位置（例如退到 484：到 420 是 2.46 半音，到 576 是 3.02 半音）。

**第 3 步 · 冲突**：
- **vs 576（最像）**：他也"高、精致、多层"。所以**砍掉原计划的 988 Hz"餐具叮"层**——"讲究"由干净承担，不由闪光承担。3 层对 4 层、62 ms 对 118 ms、零失谐对失谐双声。
- **vs 420（音高最近）**：他靠"下滑最大 + 音高不稳 + 毛刺"立身 → 三项全取反：Slide 取**正**且小、颤音浅而稳、BitCrush 恒 0。
- **vs 366（都"稳"）**：靠暖度区分——0.22 的 247 Hz 胸腔层 + 13 ms 硬爆破。

**第 4 步 · 参数**（注意包络已用正确公式反解）：

```
hz = 494，3 层，目标 62 ms
L1 主体 494 / gain 1.00 / 三角 / A 0.007 · S 0.05 · D 0.157 / Lp 0.60
         Slide +0.10 / Vibrato 0.03@0.45 / BitCrush 0
L2 胸腔 247 / gain 0.22 / 正弦 / Lp 0.45 / Slide 0 / 零颤音   ← 精确 1:2，零失谐
L3 爆破 2500 / gain 0.25 / 白噪 / 约 13 ms / Lp 0.80          ← 预渲染一次复用
```

**「喊叫」变体只改 5 项**：MasterVolume↑、Lp 0.60→0.92、颤音加大、L2/L3 gain 各降一点、**时长不变**。理由：喊叫是"更响更亮"，不是"更长更慢"。

**已知取舍**：494 在"轻"的档位，撑不住威胁性。这是故意的——那句"我只是想买点吃的！"要的是**好笑**（一个全程讲礼貌的人在喊），不是可怕。

## 落地：从参数到音色包

设计定稿只是前半程，参数写进 `packs/*.json` 才算生效。这一步有两个会**静默失败**的地方。

### 文件结构

```json
{
  "format": "dsp-voicepack/1",
  "id": "questinggoose.vanilla",
  "name": "原版音色包",
  "target": "vanilla",
  "requires": { "gameBuild": 26284217, "paramCount": 31 },
  "characters": { "officer_lun": { "...": "..." } },
  "presets": {
    "伦警官": [
      { "hz": 118, "gain": 1.0, "delay": 0, "mute": false,
        "p": { "WaveType": 0, "AttackTime": 0.025, "DecayTime": 0.16, "LpFilterCutoff": 0.50 } }
    ]
  },
  "mapping": { "officer_lun": "伦警官" }
}
```

- `target`：`vanilla` 或 `nyanko`，决定它在什么情况下自动接管
- `presets`：预设名 → 层数组；层里 `hz` / `gain` / `delay` / `mute`，其余 31 个合成参数全在 `p`
- `mapping`：角色键 → 预设名

### 三条硬规则

1. **`mapping` 的每个目标必须存在于 `presets`。** 少一个，整包被判无效，游戏里直接消失，而且**不报错**——这是最难查的一类问题。
2. **出厂包用原角色名做预设名**，不要加 `_v2`、`-fix` 之类后缀；后缀只留在本地工作台。
3. **不要手改发布 zip。** 改 pack → 跑构建脚本，脚本会校验 Release 构建、许可与源码齐全。

### 验收

```bash
python test_pack.py        # 包结构与 mapping 校验
python build_release.py    # 出包 + 哈希，产物在 dist/release-<版本>/
```

### 三个入口，别混用

| 入口 | 用途 | 生效条件 |
|---|---|---|
| 工作台 `http://127.0.0.1:8731` | 设计期试听、批量改参数 | 本地开发环境 |
| 游戏内 F11 面板 | 验收、微调 | 装好 Mod |
| `voice-request.json` | 让外部 Agent 直接改游戏内音色 | **F11 面板打开时**才轮询 |

外部 Agent 的请求格式：

```json
{ "id": "2026-10-30T14:20:00", "pack": "娘化音色包",
  "set": { "埃莉诺|0|hz": 120, "埃莉诺|0|LpFilterCutoff": 0.68 },
  "audition": "埃莉诺" }
```

`id` 变了才会重新执行；当前状态会回写到 `voice-state.json`。不联网、不开端口，面板一关就停止轮询。

接口细节见 `实时调音接口.md`，打包与许可要求见 `对接档案_上传_*.md`。
## 常见错误

| 错法 | 后果 | 正解 |
|---|---|---|
| 按线性直觉算包络 | 算出 4 ms 的"咔哒" | 用 `(a²+s²+d²)×100000` 反解 |
| 拿不到台词就自己编 | 整套参数建立在错误气质上，全废 | 停下来要原文；描述只能约束范围 |
| 用 Hz 差百分比判断"够不够分开" | 高音区实际只差半个半音 | 用 `12×log2(f2/f1)` |
| 让角色"听起来凶" | 变成噪音，且和别的凶角色撞 | 凶靠**低音区 + 长尾 + 零颤音**，不靠毛刺 |
| 追求"有戏"加很多层 | 糊、听不出音高 | 最多 4 层，每层必须有职责 |
| 只比音高不比结构 | 音高差很远但听着像 | 结构（层数/时长/失谐/毛刺）也要拉开 |
| 把气声给高冷角色 | 显得虚弱可亲 | 气声=亲近感，反着用 |
| 用低音表现"老" | 和低音区其他角色撞成一团 | **用慢速深颤音表现老**，音区可以抬 |
| 每个字符重新随机播 | 每次 tick 都不同音，等于没有音色 | 预渲染固定变体池，只做小幅音高抖动 |
| 接受"听起来还行" | 20 次后疲劳，或和某人混 | 用第 4 步的可测阈值 |
| 看名字猜波形编号 | 11 号当"蜂鸣=金属" → 纯噪声；7 号当"哨音=清亮" → 刺耳 | 查「波形真身」表，主体只用 0/1/2/4/8 |
| 只靠音高拉开角色 | 挤在同一段音区时听起来像同一个人 | 音高 + 材质分族 + 时长 + 气声，至少三项在变 |
| 把本来就是女性的角色也"娘化" | 白改一遍，还占掉一个音位 | 先核对原始性别；本来女性的角色保留原声 |
| 给没有新立绘的角色重配音 | 玩家看到的是旧立绘，声音对不上 | 只改有立绘依据的角色 |
| 出厂包的预设名加了后缀 | `mapping` 指不到预设 → **整个包被判无效，游戏里直接消失** | 出厂用原角色名；后缀只留在本地工作台 |

## 迭代方向速查

"听起来不对"但说不清哪里不对时，从这张表找方向。

| 症状 | 先动这个 | 别动这个 |
|---|---|---|
| 太尖 / 刺耳 | 降 `hz`、压 `LpFilterCutoff`、`BitCrush` 归零、削金属层 gain | 不要只降 `MasterVolume`（那是整体变小，不是变柔） |
| 太闷 / 糊 | **抬** `LpFilterCutoff`（主要）、加一点 `Overtones` | 不要靠加毛刺去"提亮" |
| 听着像别人 | 先查声学空档，再看结构（层数/时长/滑音） | 不要盲目挪音高（可能撞进另一个空档外的角色） |
| 没个性 / 像机器 | 加一点 `VibratoDepth`（0.03–0.05）、给 `Slide` 一个非零方向 | 不要加层数（糊不等于有戏） |
| 太"标准" | 检查是不是所有参数都在中位值——特色来自**偏离** | — |
| 气质完全反了 | 通常是**气声量**或**包络长短**搞反了，不是音高 | 高冷=气声少+尾短；虚弱=气声多+尾长 |

## 检查清单

设计完一个角色，逐条过：

- [ ] 每个参数能指认到一句具体台词
- [ ] 音区落在最大空档里，与最近邻居差 ≥1.5 半音
- [ ] 列出了最近的 3 个邻居，每个都有 ≥3 项具体差异
- [ ] 检查过某一层是否与别人的主层同频
- [ ] 包络时长用公式反解过，不是猜的
- [ ] 时长落在全阵容的合理档位（不要所有角色都是 70 ms）
- [ ] 层数 ≤4，每层有职责
- [ ] 刺耳度 <0.2%（或明确标注故意）
- [ ] 造了至少 2 个"故意做错"的版本，确认能靠指标排除
- [ ] 说得出这个设计的**已知取舍**（它撑不住什么场景）
- [ ] 每个角色的主体波形在 0/1/2/4/8 之内，且没有任何一族占到多数
- [ ] 最高音没有超过 ~950 Hz（女声）
- [ ] 出厂包跑过校验：每个 `mapping` 目标都能在 `presets` 里找到
- [ ] 参与改动的角色都核对过原始性别，且有立绘依据
- [ ] 跑过 `test_pack.py`，`mapping` 全部命中 `presets`
- [ ] 出厂预设名没有加后缀
